### The 7 metrics

| # | Metric | What it measures (plain English) | Formula (as implemented) | RAG band (enforced) | Direction |
|---|--------|----------------------------------|--------------------------|---------------------|-----------|
| 1 | **Test Coverage** (Stories→Test mapping) | Share of in-scope Dev stories with ≥1 linked live test case | Dev stories with linked non-abandoned test ÷ total in-scope Dev stories × 100; reported PI-to-date **and** cumulative since 2022 | Good ≥100 / Warn 70–99 / Poor <70 | Higher better |
| 2 | **Test Case Review Status** | % of closed Dev stories whose test cases were formally reviewed ("Test Case Reviewed = Yes") | reviewed ÷ closed Dev stories × 100 (resolved ≤ report date, excl. Abandoned) | Good ≥90 / Warn 70–89 / Poor <70 | Higher better |
| 3 | **Test-to-Story Ratio** | Test-coverage *depth* — avg test cases per completed Dev story | linked tests ÷ closed Dev stories, shown as `n:1` | Target **3–5 : 1** (excellent ≥5, strong ≥3, moderate ≥2) | Higher better |
| 4 | **Bug Ratio** | Bugs written per test case — proxy for test effectiveness / incoming quality | bugs ÷ test cases, shown ×100 (bugs per 100 tests) | bugDensity 15 / 5 ⚠️ see caveat | Target controlled **2–5 per 100** (lower-is-better intent) |
| 5 | **Defect Leakage / Inflow** | Live path reports **YoY defect inflow** (this week's defects vs same window a year ago) | live: ((CY26 − CY25 defects) ÷ CY25) × 100; classic `Defects ÷ (Bugs+Defects) × 100` exists in code but is bypassed | Target **<30%**; severity attention >30 / warning >40 / critical >50 | Lower better |
| 6 | **Overall Automation** | % of the *entire* test inventory that is automated | Automated ÷ total **and** Automated ÷ automatable (dual table), via "Test Status" field | Good ≥85 / Warn 40–84 / Poor <40 | Higher better |
| 7 | **Regression Automation** | % of the *regression* suite automated vs run manually | Same dual-table as #6, filtered to Test Type = Regression Testing | Good ≥85 / Warn 40–84 / Poor <40 | Higher better |

### Manual effort each metric replaced (use to fill the "before" story)
